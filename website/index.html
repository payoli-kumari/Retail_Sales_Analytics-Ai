About the Project

Project Overview

This project analyzes the Global Superstore dataset (51,290 rows, 2011–2014) using Python. It includes a complete data pipeline (cleaning → analysis → visualization → forecasting), an interactive Streamlit dashboard with 6 filters, and an AI layer that answers business questions.

Data Pipeline

4-step automated pipeline: cleaning, KPI analysis, chart generation, and Holt-Winters forecasting. Fully reproducible from raw CSV to dashboard.

  • Automated data cleaning
  • Statistical analysis
  • Chart generation
  • Time-series forecasting

Interactive Dashboard

6 sidebar filters, 5 KPI cards, and 10+ interactive Plotly charts across 5 tabs. Explore data dynamically with real-time filtering.

  • 6 sidebar filters
  • 5 KPI indicator cards
  • 10+ Plotly charts
  • 5 organized tabs

AI-Powered Insights

Ask the Data with pandas code generation, RAG-based document QA, and auto-generated business insights — all powered by LLMs.

  • Natural-language queries
  • RAG document QA
  • Auto business insights
  • Multi-LLM support

Discount Impact Analysis

Discount Band Profit Margin Impact
0% (No Discount) +25.3% Excellent
1–10% +17.2% Good
11–20% +9.9% Moderate
21–40% -17.3% Loss
40%+ -74.1% Critical Loss
Correlation: -0.316

Discounts above 20% destroy profitability. Every percentage point of additional discount in the 20%+ range leads to dramatically negative margins.

Customer Segmentation (RFM Analysis)

RFM = Recency (how recently they bought), Frequency (how often), Monetary (how much they spent). Customers are scored and segmented into actionable groups.

AI-Powered Features

Three intelligent layers that transform raw data into actionable business answers.

🤖

Ask the Data

Type a natural-language question → AI generates pandas code → executes on filtered data → returns the answer with the code shown for verification.

Example
"What is the most profitable sub-category?"
Question Pandas Code Answer
📚

Ask the Project (RAG)

Documents are split into paragraphs → TF-IDF finds the 3 most relevant paragraphs → AI answers only from those sources → answers from project documentation, not the raw data.

Example
"How does the forecasting model work?"
Docs TF-IDF Context Answer
💡

Click a button → dashboard calculates summary stats with pandas → AI writes 5 key insights + 3 business recommendations → all based on the current filtered view.

Key Findings & Recommendations

Data-driven recommendations to improve business performance.

01

Control High Discounts

Orders above 20% discount have negative margins. Limiting excessive discounts can significantly improve profitability. The data shows a clear correlation of -0.316 between discount and profit.

Improve Furniture Margin

Impact
